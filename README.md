## What this is

Three products on one stack. Not three businesses.

**Mission Control** — a single pane of glass over business operations. AIOps, MLOps and
LLMOps in one console, with the view filtered by the role reading it. This is the thing
PwC Middle East & Africa asked for in writing.

**Black Cloud Node** — a handheld sovereign inference appliance. The agent fleet, local
model weights and the console itself, running with no network at all. This is the thing
Rwanda asked for: AI on bare metal, offline, inside a private local environment.

**The Data Centre** — the physical floor. Cape Town targeted for October 2026, modular
African nodes after that.

Cloud-only agents do not solve the African problem. Connectivity costs, data privacy and
sovereignty rules all push the same direction: the compute has to be able to sit in the
building. That constraint is the product.
