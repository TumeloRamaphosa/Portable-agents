# Coffee launch checklist

High-level readiness for the coffee launch on **16 November 2026** in Cape Town. This is a checklist, not a run of show, and it is not an announcement.

Strategic north star (phases 0–1): [`afrique-noir-strategy-brief.md`](afrique-noir-strategy-brief.md). Storefront launch ≠ marketplace streaming; fiat trades and EUDR data come before stablecoin settlement.

The packaging and launch-kit work lives in [studex-coffee pull request 38](https://github.com/TumeloRamaphosa/studex-coffee/pull/38). Use that pull request as the source for artwork and kit files. Do not copy those files into this folder.

Nothing in this checklist is printed, published, or announced without Agent Chief Lord's yes.

## Open before launch

- **Back label placeholders.** The back label still needs a registration number and a roaster name and address. Those values are not written here.
- **Origin lock.** The origin decision is still open. Do not print or publish origin claims until it is locked.
- **Pricing.** Retail pricing is still pending a supplier quote. No prices are recorded in this folder.
- **Storefronts and campaign sites.** Public coffee sites still need to go up before launch. Publishing them is a human approval, not an agent action.
- **Packaging and kit.** Continue from pull request 38. Treat further label or kit changes as drafts until approved.
- **Public wording.** Any launch copy, press note, or customer-facing script stays in draft until approved.

## Day-of posture

- Bring a short readiness report to the owner and the agent meeting: what is approved, what is still open, and what is blocked.
- Do not improvise prices, origin claims, partner names, or print changes on the day.

## After this folder can be expanded

Once the repository is private, this checklist can be filled in with the held-back commercial and supplier detail. Until then, keep updates at this same level of generality.
