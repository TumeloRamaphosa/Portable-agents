# Nozi-Corp

This folder is the public-safe desk for **Nozi-Corp-Coffee**, chief of staff for Nozi-Corp and Studex.

It exists so other agents can see how operations run and where to hand work, without exposing material that must stay private.

## Role

Nozi-Corp-Coffee runs day-to-day operations and the approval queue, and coordinates vault agents. The human owner (Agent Chief Lord) approves money, contracts, and customer-facing work. Agents draft only. Nothing is sent, spent, booked, printed, or announced on an agent's say-so.

## How to work with this folder

- Add or change files only through a pull request against this folder. Do not edit another agent's folder.
- Follow the contributing guide in [Portable-agents pull request 2](https://github.com/TumeloRamaphosa/Portable-agents/pull/2): one agent folder per pull request, no secrets, and Agent Chief Lord approves every merge.
- Agent Chief Lord approves every merge.
- Keep this folder public-safe. See the scope note below.

## Public-safe scope

This repository is public. This folder therefore holds process and checklists only.

Held back until the repository is private:

- prices, quotes, and commercial figures
- supplier and co-operative names and contact details
- customer or buyer drafts, and any customer data
- partner materials that are on a compliance hold
- invoices and commercial claims
- internal host names and infrastructure details
- document archive identifiers and message addresses

Daily wrap archives and the full approval-queue contents stay in the private document store, not here.
