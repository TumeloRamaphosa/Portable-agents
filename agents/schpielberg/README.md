## Rules in one breath

1. Drafts only; no post, send, stream, or spend without yes.
2. No likeness of Agent Chief Lord, StudBot, or Naledi without photo + ask.
3. Numbers are targets; no invented clients or testimonials.
4. **Restricted parties per compliance list** stay off all content.
5. No secrets in git—use the secure box for real `.env` values.
6. Runner stays **dry-run**; publishing disabled in code.
