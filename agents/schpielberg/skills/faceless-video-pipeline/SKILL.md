# Faceless video pipeline (SCHPIELBERG)

## When to use

- A new **9:16 or YouTube short** without on-camera talent
- Moving an item from **Idea → Script** in the content-pipeline model
- First reference: [`work/faceless-video-midnight-whatsapp.md`](../../work/faceless-video-midnight-whatsapp.md)

## Required reading

1. [`memory/standing-rules.md`](../../memory/standing-rules.md)
2. [`work/new-dawn-wiki/rules.md`](../../work/new-dawn-wiki/rules.md)
3. [`INDEX.md`](../../INDEX.md) — pick canon scripts to match tone

## Workflow

### 1. Brief lock (one screen)

- Hook (≤ 12 words)
- Product tie-in (StudBot Rise / Agentic Rise — no invented pricing)
- CTA type (membership, site visit) as **target**, not guaranteed conversion
- Explicit: no likeness, no restricted parties per compliance list

### 2. Draft in New Dawn shape

Create or update markdown with:

- Title, runtime target (e.g. 60s)
- Five beats (cold open → tension → product bridge → proof style → CTA)
- VO label: Studbot, third person
- On-screen text list (short straps, monospace styling per brand rules)

Save under `work/` or `work/new-dawn-wiki/scripts/` with `DRAFT` in the filename until approved.

### 3. Claim-check

Use EP01 pattern: [`work/films/ep01-he-herds-ai-agents-now/04 - claim-check.md`](../../work/films/ep01-he-herds-ai-agents-now/04%20-%20claim-check.md).

- Every stat → source or reframe as target
- Remove partners, governments, and held names unless cleared
- No infrastructure on screen (blur checklist in Agentic Rise plans applies)

### 4. Storyboard stub (optional)

Bullet frames only—no generation. Reference Higgsfield plan only for **future** shot lists; do not spend credits in this skill.

### 5. Pipeline handoff (optional, dry-run)

If aligning with the dashboard runner:

- Read [`runner/README.md`](../../runner/README.md)
- Item fields: `title`, `brief`, stage `idea` or `script`
- Runner stays **dry-run**; script step writes local `script-draft.txt` only when keys are configured off-repo

### 6. Stop before publish

Output a handoff block:

- Draft paths
- Open claim-check flags
- **Approval needed for**: generation, voice, upload, Blotato

## Outputs

- Markdown script + optional storyboard stub
- No binary renders from this skill alone

## Never

- Post, schedule, or upload
- Generate likeness of Agent Chief Lord, StudBot, or Naledi
- Turn off `PIPELINE_DRY_RUN` or call blocked hosts (see `runner/runner.py`)
